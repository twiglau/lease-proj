# 2026-11-21 工作日志

## 修复 git 访问 gitee 报 7897 端口连接失败

现象：`fatal: unable to access 'https://gitee.com/lyfyzs/public_chain.git/': Failed to connect to 127.0.0.1 port 7897`

### 根因
`~/.gitconfig` 全局配了 `http.proxy` / `https.proxy = 127.0.0.1:7897`，但本机代理软件未运行（7897/8281/33331 端口均无监听）。
`scutil --proxy` 显示系统代理全关；当前活跃网络服务是 Ethernet(en0)，Wi-Fi 上配的 SOCKS 实际不生效。
Gitee 是国内站，直连可达（`git -c http.proxy= ls-remote` 成功返回 HEAD）。

### 修复
在 `~/.gitconfig` 增加针对 gitee 的例外，保留全局代理供 GitHub 等境外站使用：
```ini
[http "https://gitee.com/"]
	proxy =
```
坑：`git config --global` 写入报 `could not lock config file .gitconfig: File exists`（残留 `.gitconfig.lock`，内容为写了一半的新配置，沙箱拦截了文件替换）。
改用直接 Edit 写 `~/.gitconfig` + 手动 `rm -f ~/.gitconfig.lock` 解决。

### 验证
`git ls-remote https://gitee.com/lyfyzs/public_chain.git HEAD` 返回 commit hash，成功。
全局代理 7897 仍保留，将来启动代理软件后 GitHub 可用。

## 本机代理配置排查结论（macOS 26.6.2）
- 代理有四个层面：系统网络代理（networksetup/scutil）、shell 环境变量、工具进程环境变量、代理软件进程。
- 当前状态：Wi-Fi 配了 SOCKS 127.0.0.1:7897 但因走 Ethernet 不生效；代理软件未运行；shell 无代理配置；
  工具会话注入的 HTTP_PROXY=127.0.0.1:54733 非本机配置。
- GUI 位置：系统设置 → 网络 → 选中服务 → 详细信息 → 代理。
- 排查命令：`networksetup -getwebsocksfirewallproxy/-getsecurewebproxy/-getwebproxy "Wi-Fi"`、`scutil --proxy`、`env | grep -i proxy`。
