# maven-archetype 选项

| 条目 | 生成内容                                                        |
|-----|-------------------------------------------------------------|
|maven-archetype-archetype | 造模版的模版--用来创建你自己的archetype                                   |
|maven-archetype-j2ee-simple| 传统Java EE 简单应用(EJB,WAR,多模块)                                 |
|maven-archetype-plugin(出现两条，一般是同一模版的不同版本) | Maven插件项目，用来写自己的Maven插件(mojo)                               |
|maven-archetype-portlet | JSR-268 Portlet 门户组件项目                                      |
|maven-archetype-profiles | 演示Maven profile(多环境切换) 用法的示例工程                              |
|maven-archetype-quickstart| 最基础的Java项目：一个App.java + AppTest.java(JUnit 4)               |
|maven-archetype-site/-site-simple | 带Maven Site 文档站点的项目(完整版/简化版)                                |
|maven-archetype-webapp | 传统 Java Web 项目：WAR 包， web.xml, src/main/webapp, JSP/Servlet |
